# 閱讀頁

這份已經做進 app。下面是當時的底稿，搜尋和書籤按鈕的行為仍沒有。點查是下半個畫面，只有關閉，內容留空。

建議的預設已採用：句末 `。！？`，細段 `，、；：`，頁數是這一章的第幾頁，上下列 4 秒後消失，直排時左右對調，劃線的頁角不對調。版面數字用第二份計畫那張表。

## 不要重做的

- 沒有書店，也沒有後端。書留在這支手機上。
- 搜尋、書籤按鈕：位置在，行為還沒有。
- 點查的解釋還沒有。
- 手錶還沒有。

`docs/plan-2-settings.md` 把字級、行距、邊界、字型放在設定頁，並寫閱讀頁不要這些按鈕。這份改成放在閱讀頁的版面面板。兩份衝突時，以你留在這份裡的為準。

## 這一輪先不要做的

- 點查的解釋。下半個畫面已經在，內容是空的。
- 上方 search 和書籤的行為。
- 手錶。
- 書店、帳號、雲端同步。

全 app 仍不要動畫。下面寫「出現」「消失」「由左出現」都是立刻切換，不要滑入、不要淡出。

## 句陣列

一次只處理目前這一章（spine 的一項）。把這一章走成一個 array。一筆是一句。TTS 照這個 array 走。

Readmoo 會在原文 class 後面再加自己的 class：`moofs16` 這類是字級，`moolh27` 這類是行距，`non-moofont` 是不要用 Readmoo 字型。這些只影響他們的閱讀器，**不拿來判斷類型**。類型看原本的標籤和 class。

### 一塊怎麼定類型

依文件順序走區塊。同一塊裡的句子共用這個類型。

| 類型 | 這一本裡怎麼認 | TTS |
| --- | --- | --- |
| `title` | `h1`–`h6`；`p.leading`、`p.leading1`（章號，如 `[1]`） | 念 |
| `content` | 沒有下面那些語意 class 的 `p`；`li` | 念 |
| `list` | `p.p22`、`p.p01`、`p.p02`、`p.p04`、`p.p05`、`p.p11` 這類縮排條目 | 念 |
| `quote` | `p.kai`、`p.kc`、`p.kai-indent-5em`、`p.letter`、`blockquote`、`.quotes` | 念 |
| `caption` | `p.caption`、`p.caption-b`、`p.caption01` | 念 |
| `note` | `class` 含 `footnote` 或 `footnote0`，或 `epub:type="footnote"` | 不念 |
| 不進 array | 圖（`div.picbox`、`p.pic`、`img`、`svg`）、`hr`、只有空白或 `　` 的 `p`、`p.ct`（如 `※※※`） | 沒有句子 |

行內強調留在同一句裡，不另成一筆，也不改類型：`span.kais`、`span.kai`、`span.italic`、`span.sans`、`span.dash`、`span.bracket`、`span.emph`。

正文裡的註釋號碼拿掉，不進 array，也不留在句子文字裡：`a.ref`、`epub:type="noteref"`。這一本有兩種寫法，都拿掉：`1` 和 `[1]`。註釋正文是 `note`，整筆不念，裡面的 `span.no`（號碼）一起不念。

### 一句、再切細段

一塊的文字先拼起來（拿掉註釋號碼）。`<br>` 當成細段的分界，不當成新的一句。

沒有句末標點的一塊，整塊就是一句。例如章名「又舊又新的電玩」。

建議的句末：`。！？`。英文句號先不切。這一本很多 `J. M. Graetz`、`(Nintendo 2003a)`，用 `.` 切會切壞。

一句再切細段，分界是：`，、；：`。分界標點留在前一段的結尾。不要切進 `「」『』《》（）` 裡面。英文逗號先不切。

一筆長這樣：

```text
type: content
text: 本書原文以「半真實」（Half-Real）為名，意指電玩遊戲同時具有兩種面向。
segments:
  - 本書原文以「半真實」（Half-Real）為名，
  - 意指電玩遊戲同時具有兩種面向。
```

這句來自 `ch01.xhtml` 第一段正文。`span.kais` 的「真實」留在後面那句裡，不單獨成筆。

TTS 反白的是整句，不是細段。細段先存著，給之後的停頓用。這一輪不要為細段做上一句、下一句以外的按鈕。

章名例子：`h2`「入門」加 `<br>` 加 `span.bracket`「Introduction」，是一句 `title`，細段兩段：`入門`、`Introduction`。

## 閱讀頁

內容全螢幕。介面收起時，畫面上只有頁數。

一次仍只載入一個章節，不要整本書畫進 WebView。頁是這一章排版之後的頁。左緣上一頁，右緣下一頁。這一章的最後一頁再下一頁，載入下一章的第一頁；第一頁再上一頁，載入上一章的最後一頁。第一頁的上一頁、最後一章最後一頁的下一頁，沒有動作。

建議頁數是「這一章的第幾頁／共幾頁」，收起時也留著，放在底部中央。

點畫面分成左、中、右三塊。左、右是翻頁。中間點一下，上方和下方的列立刻出現。再點中間，或過一段時間，兩列立刻消失。秒數請填在文末；沒填之前建議 4 秒。有面板開著時不要自己消失。

翻頁、出現、消失都不要動畫。

直排時建議：右緣是上一頁，左緣是下一頁（直排由右往左讀）。請改。

### 上方

三個文字按鈕：回到書櫃、search、書籤。

search 的行為後補，見文末。

書籤按鈕和下面的臨時書籤不是同一件事。按鈕本身是加一筆固定書籤，還是打開書籤列表，請在文末寫。沒寫之前不要做這個按鈕的內容，位置先留著。

### 下方

三個文字按鈕：版面、目錄、劃線。

**版面**蓋在內容上，不要新畫面。項目用文字按鈕，選中的立刻加框，並在文字後加「（使用中）」。不要滑桿，不要會滑動的開關。選擇要記住。改完只重排目前這一章，停在原來那一句附近，不要整本書重畫。

| 項目 | 選項 | 建議預設 |
| --- | --- | --- |
| 邊界 | 窄、標準、寬 | 標準 |
| 橫直排 | 橫排、直排 | 橫排 |
| 字型 | 黑體、明體 | 黑體。系統字，不內嵌，不下載 |
| 字級 | 小、偏小、標準、偏大、大 | 標準 |
| 行距 | 緊、標準、鬆 | 標準 |
| 主題 | 沿用設定頁那四個：白、黑、淺色、深色 | 沿用目前主題 |
| 翻頁方式 | 翻頁、捲動 | 翻頁 |

數字若要跟 `docs/plan-2-settings.md` 的表，你寫在文末。這份不另訂像素。

**目錄**由左邊立刻出現，蓋住一部分內容。不要滑入。

這一本的 `toc.ncx` 只有一層（封面、各章、譯後記）。細章在章檔裡面：`h2` 是章名，`h3` 是節，`h4` 是細節。目錄用 toc 的一層當章，章底下用該檔的 `h3`，`h3` 底下用它後面的 `h4`，直到下一個 `h3`。`h4` 若出現在第一個 `h3` 之前，掛在這一章底下。

章可以收合、展開。`h3` 也可以收合、展開它的 `h4`。建議打開目錄時，只展開目前這一章，其他章收合。點一筆就關掉目錄並跳到那裡。

**劃線**同樣蓋在內容上。列出這本書的劃線。點一筆，關掉並跳到當時的位置。

### 臨時書籤

用目錄、劃線，或其他方式一次跳過一頁以上時，在離開的那一頁放一筆臨時書籤。左右翻一頁、TTS 讀到頁尾自動翻頁、劃線時擦到頁角而翻頁，都不放。

臨時書籤出現在左上角。點一下回到那一頁。長按刪掉那一筆。

最多三筆。要放第四筆時，刪掉最舊的。

### 長按

長按中文（或不是英文字的位置）：先選中手指下的那一整句（用上面的 array），再讓使用者拖範圍。選好之後可以複製，或劃線。

長按的位置是英文字：不選整句，改觸發點查，對象是那個英文詞。點查的內容後補。

劃線進行中，手指進到畫面最左上角就上一頁，最右下角就下一頁，方便劃過兩頁。這只在劃線拖曳時發生。直排時這兩個角要不要對調，請改；沒改就仍是螢幕的左上角和右下角。

## TTS

開了之後，內容區變矮，下面出現 TTS 列。用語系 TTS 發聲。反白目前這一句。`note` 整筆跳過，正文裡已拿掉的註釋號碼也不念。

列上兩個大按鈕：播放／暫停、停止。後面一顆三點。點三點再選來源、語言和速度。來源是系統或雲端；雲端不能選。語言是廣東話（預設）、國語、英文，對到這支手機的系統語音。速度用文字按鈕，建議：慢、偏慢、標準、偏快、快。

讀到這一頁的最後一句，自動翻到下一頁，繼續念。

比這多的 TTS 行為後補。手錶不在這份。
